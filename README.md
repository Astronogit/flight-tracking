# Flight tracking

Carnet de vol personnel : un globe interactif de mes trajets, un passeport de vol et des statistiques (distance, temps de vol, aéroports, compagnies, avions).

Application web installable sur iPhone (Safari › Partager › Sur l’écran d’accueil).

Les vols sont enregistrés uniquement dans le navigateur de l’appareil : ils ne sont jamais envoyés sur GitHub. Pensez à faire un export de temps en temps pour garder une sauvegarde.
